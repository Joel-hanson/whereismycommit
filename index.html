W Where Is My Commit

Trace changes into releases

Small GitHub tools for support, release notes, and “did this ship yet?”

Find the release

  • C Where Is My Commit SHA → first release tag. Direct or via the PR that merged it (squash-safe). Open →
  • P Where Is My PR PR number or URL → first tag and release lines that include the merge. Open →
  • ? Is It In This Version? Yes/no: is this commit or PR contained in a specific tag (e.g. 3.9.1)? Open →

Plan the release

  • Δ What Changed Between Commits (and detected PRs) that landed from one tag to another. Open →
  • ↑ What's Unreleased What's on the default branch since the latest version tag — not shipped yet. Open →
